# Market Basket Analysis Using Association Rule Mining

![image](https://github.com/user-attachments/assets/478f5dd3-e45c-44b2-abf3-8b3e44acc191)

1. Project Objectives
   
* Analyze Point-of-Sale (POS) data to discover frequently bought product combinations
* Generate strong association rules to inform cross-selling and up-selling strategies
* Recommend product bundles and offers that align with real-world buying behavior
* Boost store revenue by increasing average basket size and encouraging repeat purchases
  
2. Key Highlights
   
* Conducted exploratory data analysis to uncover key seasonal, weekly, and category-based trends in sales
* Applied association rule mining with optimized thresholds for support and confidence
* Identified high-lift product combinations (e.g., "Bread & Butter", "Milk & Eggs") ideal for promotional combos
* Designed KNIME workflows to automate and visualize the rule extraction and evaluation process
